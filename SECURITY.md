# Política de segurança

## Versões suportadas

O projeto está em evolução ativa. Correções de segurança são aplicadas à versão mais recente publicada e, quando necessário, documentadas nas notas da versão.

## Como reportar uma vulnerabilidade

Não publique vulnerabilidades exploráveis, segredos ou dados pessoais em uma issue pública.

Use o recurso **Private vulnerability reporting** do repositório no GitHub. Se ele não estiver disponível, abra uma issue sem detalhes sensíveis solicitando um canal privado de contato.

Inclua, quando possível:

- versão e sistema operacional;
- impacto observado;
- passos mínimos para reprodução;
- evidências sem dados pessoais nem credenciais;
- sugestão de correção ou mitigação.

Você receberá uma confirmação inicial assim que o relato for triado. A divulgação pública deve ocorrer somente depois de uma correção ou mitigação estar disponível.

## Escopo sensível

O Organon manipula dados locais, notas, áudio, tokens opcionais de integração e caminhos do sistema. Relatos envolvendo perda de dados, travessia de diretório, execução arbitrária, exposição de credenciais, atualização insegura ou quebra do isolamento do Electron são tratados como alta prioridade.
