## ✨ Visão Geral

O **Organon Desktop** é um ambiente integrado de produtividade e gestão do conhecimento, desenvolvido com arquitetura **Local-First**. Seus dados pertencem a você e ficam armazenados localmente no seu computador, com funcionamento offline completo e sincronização peer-to-peer/Wi-Fi opcional.

---

## 🚀 Principais Funcionalidades

### 📅 1. Planejamento & Execução Visual
- **Sprint Board**: Visualização estilo Kanban com suporte a colunas customizadas, raias (swimlanes) e backlog dinâmico.
- **Grade Horária & Calendário**: Planejamento diário e semanal por blocos de tempo com suporte a eventos recorrentes.
- **OKRs & Metas**: Acompanhamento de objetivos e resultados-chave de curto e longo prazo.

### 🎯 2. Modo Foco & Pomodoro
- **Timer Inteligente**: Ciclos de foco, pausas curtas e pausas longas personalizáveis.
- **Seleção de Metas Ativas**: Associe o tempo de foco diretamente a cards e metas específicas.
- **Sons Ambientes & Analytics**: Ruído branco, trilhas sonoras e histórico de sessões com métricas diárias.

### 📚 3. Conhecimento & Documentação
- **Editor Rico (Wysiwyg)**: Suporte completo a Markdown, listas de tarefas, blocos de código e diagramas Mermaid.
- **Canvas Infinito**: Desenhe diagramas arquiteturais e fluxogramas diretamente no app integrado com Excalidraw.
- **Playbooks de Comunicação**: Crie e reuse scripts e fluxos estruturados com facilidade.
- **Biblioteca Local**: Centralize documentos e referências.

### 🎙️ 4. Whisper Transcrições & Ditado por Voz
- Transcrição local de áudios e ditado rápido de notas e tarefas via inteligência artificial.

### 🛠️ 5. Ferramentas & Git Engine
- **Projetos & Git**: Monitoramento em tempo real de repositórios locais, commits recentes, branches e relatórios de velocidade.
- **Clipboard Manager**: Histórico da área de transferência com categorização e snippets favoritos.
- **Paletas de Cores**: Gerencie paletas visuais para seus designs e interfaces.

## 📦 Como Instalar e Rodar Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- [npm](https://www.npmjs.com/) ou [pnpm](https://pnpm.io/)

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/PedroReoli/organon.git
   cd organon
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o modo de desenvolvimento (Vite + Electron):**
   ```bash
   npm run dev
   ```

4. **Para gerar o instalador de produção:**
   ```bash
   npm run dist
   ```

## 🔒 Privacidade & Segurança

- **100% Local-First**: Todos os cartões, notas, transcrições e dados permanecem no seu disco local por padrão.
- **Sem Rastreamento**: Zero telemetria invasiva ou envio não autorizado de dados a servidores externos.
- **Sync Opcional**: A sincronização com backend é puramente opcional.
